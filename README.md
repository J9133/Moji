# Moji

A fast, simple character map for Linux. Every Unicode character in **one continuous scrolling view**, with a jump list on the right that takes you straight to any block.

Written in C with GTK4. The grid is drawn by hand and only the visible cells are rendered, so scrolling through ~150,000 characters stays instant and the app starts in a fraction of a second.

![Moji](screenshots/main.png)

## Features

- **One continuous view** of every assigned Unicode character, with a sticky header for the current block.
- **Jump list** of all 321 blocks on the right. It follows your scroll position, and clicking an entry jumps there.
- **Two orderings:** by code point (U+0000 to the end) or grouped by category (Latin, Symbols & Emoji, Math & Technical, Middle Eastern, East Asian, ...).
- **Search** by name (`smiling face`), by character (`é`), or by code point (`1F600`, `U+0645`, `0x263A`). Just start typing anywhere.
- **Details panel:** name, code point, decimal, UTF-8, UTF-16, HTML entity, general category and block.
- **Text collector:** double-click (or press Enter on) characters to build a string, then copy it in one go.
- **Right-click** any character to copy it instantly.
- Full keyboard navigation.

## Install

### Dependencies

| Distro | Packages |
|---|---|
| Arch | `gtk4 base-devel` |
| Debian / Ubuntu | `libgtk-4-dev build-essential pkg-config` |
| Fedora | `gtk4-devel gcc make pkgconf-pkg-config` |

For the glyphs to actually show up you also need fonts. On Arch:

```sh
sudo pacman -S noto-fonts noto-fonts-emoji noto-fonts-cjk
```

Characters your fonts don't cover are drawn as empty boxes. Rare scripts may need extra fonts such as `noto-fonts-extra`.

### Build and install

```sh
git clone https://github.com/<your-user>/Moji.git
cd Moji
make
sudo make install        # installs to /usr/local (change with PREFIX=...)
```

Or just run it from the build folder: `./moji`

To uninstall: `sudo make uninstall`

## Usage

| Action | Result |
|---|---|
| Click | Select a character |
| Double-click / `Enter` | Add the character to the text collector |
| Right-click / `Ctrl+C` | Copy the character |
| Arrow keys, `PgUp` / `PgDn` | Move the selection |
| `Home` / `End` | First / last character |
| Type anything | Start searching |
| `Esc` | Clear the search (you land back on the character you selected) |

### Hyprland

Optional keybind and a floating window rule (the window class is `local.Moji`):

```
bind = SUPER, period, exec, moji
windowrule = float, class:^(local.Moji)$
```

## How it works

- Block ranges and character names are embedded in `ucdata.h`, so Moji needs no data files at runtime.
- Names for CJK ideographs and Hangul syllables are generated algorithmically instead of being stored. This keeps the header small, but those characters can't be searched by name (search by character or code point instead).
- Character categories come from GLib.
- `ucdata.h` is generated by `gen_ucdata.py` (current data: Unicode 15.0). To regenerate it:

```sh
pip install fonttools
python3 gen_ucdata.py
```
